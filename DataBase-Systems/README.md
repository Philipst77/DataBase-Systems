# 🗄️ DataBase-Systems  

A collection of **relational database projects** built with **PostgreSQL, PL/pgSQL, JDBC, and Java**, focusing on both backend database design and interactive applications.  
The projects demonstrate how to design schemas, write advanced queries, implement transactions, and build CLI/GUI applications that interact with real-world data.  

---

## 📂 Repository Structure  

- **DataBase-Systems/**  
  - Java-based database projects using **JDBC**  
  - CLI/GUI applications for managing books, transactions, and real-world datasets  
  - Demonstrates SQL integration with object-oriented programming  

- **PostgreSQL/**  
  - SQL scripts, schema definitions, and stored procedures  
  - **PL/pgSQL functions** for triggers, automation, and business logic  
  - Example queries for data retrieval, joins, aggregations, and reporting  

---

## 🚀 Features  

- **Relational schema design** – tables, constraints, keys, and normalization  
- **SQL queries** – SELECT, JOIN, GROUP BY, subqueries, and aggregations  
- **PL/pgSQL procedures** – triggers, stored functions, and control logic  
- **Transactions & ACID** – commit, rollback, and isolation levels  
- **Java JDBC integration** – connect applications to PostgreSQL  
- **CLI/GUI apps** – user-friendly interfaces for database interaction  

---

## 🛠️ Technologies  

- **PostgreSQL** – relational database system  
- **PL/pgSQL** – stored procedures and functions  
- **SQL** – query language for data retrieval and manipulation  
- **Java** – backend logic and database connectivity (JDBC)
